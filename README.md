# Yaniv Assaf's Lab - fNIRS Analysis Pipeline

## File and Folder Structure

* `src/*.py`: Source files and core logic.
* `tools/*.py`: Auxiliary utility scripts (e.g., `.snirf` editor, data viewers).
* `lib/*.py`: Library files used by both tools and main analysis pipeline.
* `data/`: Central repository for all research data.
    * `raw/*.{snirf, xml}`: Raw data collected from subjects.
    * `labeled/*.npz`: Labeled data after matching with the subject table (output of `src/label.py`).
    * `analyzed/*.npz`: Processed and analyzed data (output of `src/analyze.py`).
    * `templates/*.npz`: Group-level templates used for comparative analysis (output of `src/template.py`).
    * `subjects.csv`: Comprehensive subject metadata and lookup table.
* `images/*.png`: Visual outputs, plots, and figures generated by scripts.
* `requirements.txt`: List of Python dependencies required to run the toolkit.
* `main.py`: Entry point for the program, which runs all analysis steps.
* `README.md`: Project documentation and instructions.
* `LICENSE`: Legal permissions and usage terms.

## Pipeline
The processing pipeline starts by converting the raw data to Hb levels and labeling it according to the subject data table. Then, the data gets filtered, regressed by SSC data, chopped into trials and baseline-subtracted. Templates are then generated from these analyzed samples, one for each belt or each training time bracket (configurable). At the end of the pipeline, the analyzed data's and the templates' channels are correlated to generate correlation matrices, which get compared to the templates' correlation matrices to create scores which will be used to tag subjects and attempt to quantify their skill.
